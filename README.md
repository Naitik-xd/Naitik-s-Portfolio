## 🌌 The Vision
This is not just a standard web portfolio; it is an interactive experience. Built with a core philosophy of **Prompt Engineering, AI Tool Scouting, and No-Code Development**, this portfolio features a fully autonomous AI agent that speaks on my behalf, answers recruiter questions, and dynamically tracks user engagement.

## ✨ Core Capabilities

*   **🤖 Custom "Ask Naitik" AI Agent:** A context-aware Gemini AI chatbot that acts as my personal representative, answering questions about my skills, projects, and achievements.
*   **🔔 Real-Time Discord Telemetry:** Integrated backend webhooks that instantly notify my private Discord server the moment a new user starts a chat session, capturing their name and contact info.
*   **🛡️ Enterprise-Grade Security:** Custom Express.js backend featuring Supabase-powered rate limiting (3-strike ban system), XSS input sanitization, and hidden API keys.
*   **🌗 Fluid UI/UX:** A highly polished, responsive interface with seamless Dark/Light mode transitions, typing indicators, and beautiful gradient animations.

---

## 🛠 The Arsenal (Tech Stack)

*   **Frontend:** React 18, Vite, Tailwind CSS, HTML5/CSS3
*   **Backend:** Express.js, Node.js
*   **Database:** Supabase (PostgreSQL) for session tracking and rate-limiting
*   **AI Integration:** Google Gemini API (`@google/genai`)
